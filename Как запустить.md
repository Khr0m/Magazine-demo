8. Инструкция по запуску
8.1. Подготовка системы (Windows 10)
Установите Docker Desktop:

Скачайте с официального сайта

Установите с настройками по умолчанию

После установки запустите Docker Desktop

Установите Python (если нужна локальная разработка):

Скачайте Python 3.9+ с python.org

Во время установки отметьте "Add Python to PATH"

Установите Git:

Скачайте с git-scm.com

8.2. Создание структуры проекта
Откройте PowerShell от имени администратора

Создайте папку проекта и перейдите в нее:

powershell
mkdir C:\Magazine-demo
cd C:\Magazine-demo
Создайте структуру папок:

powershell
mkdir catalog_service, order_service, prometheus, grafana\provisioning\datasources, grafana\provisioning\dashboards
Скопируйте все файлы кода в соответствующие папки

8.3. Запуск системы
Перейдите в корневую папку проекта:

powershell
cd C:\Magazine-demo
Соберите и запустите контейнеры:

powershell
docker-compose up --build -d
Проверьте статус контейнеров:

powershell
docker-compose ps
8.4. Проверка работоспособности
Микросервис каталога:

powershell
# Проверка здоровья
curl http://localhost:8001/health

# Получение товаров
curl http://localhost:8001/products

# Получение метрик Prometheus
curl http://localhost:8001/metrics
Микросервис заказов:

powershell
# Проверка здоровья
curl http://localhost:8002/health

# Создание заказа
curl -X POST http://localhost:8002/orders ^
  -H "Content-Type: application/json" ^
  -d "{\"customer_id\":\"cust-001\",\"items\":[{\"product_id\":\"1\",\"quantity\":2}],\"shipping_address\":\"Москва, ул. Примерная, 10\"}"

# Получение заказов
curl http://localhost:8002/orders
Prometheus:

Откройте в браузере: http://localhost:9090

В меню Status → Targets проверьте, что все сервисы UP

Grafana:

Откройте в браузере: http://localhost:3000

Логин: admin, пароль: admin123

Создайте новый дашборд с метриками микросервисов

8.5. Создание дашборда в Grafana
Войдите в Grafana (http://localhost:3000)

Нажмите "+" → "Create" → "Dashboard"

Добавьте панели для следующих метрик:

Панель 1: Общее здоровье системы

Query: up

Visualization: Stat

Панель 2: Запросы к сервисам

Query: rate(product_requests_total[5m])

Query: rate(order_requests_total[5m])

Visualization: Graph

Панель 3: Время ответа

Query: histogram_quantile(0.95, rate(product_request_duration_seconds_bucket[5m]))

Query: histogram_quantile(0.95, rate(order_request_duration_seconds_bucket[5m]))

Visualization: Graph

Панель 4: Созданные заказы

Query: rate(orders_created_total[5m])

Visualization: Graph

Панель 5: Стоимость заказов

Query: order_value_rub_sum

Visualization: Stat
